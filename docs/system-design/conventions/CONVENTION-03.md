# CONVENTION-03: In text mode, results go to standard output and notices go to the error stream

In text mode, results go to standard output, and notices, progress, and the cost line go to the error stream. In structured mode, everything goes to standard output, inside the document (conventions-3, DECISION-29, DECISION-41).

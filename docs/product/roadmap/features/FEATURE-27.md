# FEATURE-27: README examples for people

The README gets worked examples for a person at the shell: the operator (PERSONA-02), the knowledge seeker (PERSONA-03), and the shell power user (PERSONA-04). Each example gives a command that the person can copy, and what jag shows. Today the README explains each option, but it has no worked example with its output. The examples are for people, not instructions for an agent (FEATURE-24 has the agent side).

Source: the user, in the hitl card on ADR-0025, 2026-10-20: "We need some examples in the readme for users on how to use JAG." The specifier asks the rule for the set of examples (Ask the Rule).

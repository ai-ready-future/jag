# CRITERION-138: Each new push or edit of a fork pull request needs a new approval

After an approved run, a new push to the test fork pull request starts no scan until a maintainer approves the new run. An edit of its title or body also starts no scan until a maintainer approves the new run. The earlier approval does not apply to the new run.

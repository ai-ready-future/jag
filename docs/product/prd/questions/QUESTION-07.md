# QUESTION-07: Does turning the private-pattern check off also turn off the built-in list?

The user can turn the private-pattern check off. Does that turn off the built-in list, the list of the user, or both?

**Answer (2026-10-29):** Both. One setting turns off the two lists, and the report says that the check is off. See [DECISION-80](../decisions/DECISION-80.md).

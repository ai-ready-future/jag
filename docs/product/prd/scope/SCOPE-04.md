# SCOPE-04: After release 1: local model option

The release after release 1 ships before release 2 and release 3. It serves the operators and the knowledge seekers who cannot send their text to an outside service ([DECISION-57](../decisions/DECISION-57.md)). The user can score with a Clef server that the user runs, and jag holds private text back from each model service.

# CONSTRAINT-09: The README shows people how to use jag with examples

The README of jag gives worked examples for a person at the shell: the operator, the knowledge seeker, and the shell power user. Each example shows a command that the person can copy and what jag shows. The examples are for people. They are not instructions for an agent; the agent side is CONSTRAINT-08 and CAPABILITY-11.

Source: the user, in the hitl card on ADR-0025, 2026-10-20: "We need some examples in the readme for users on how to use JAG."
